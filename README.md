# AI Resume Analyzer

An AI-powered Resume Analyzer that helps job seekers evaluate their resumes against job descriptions, identify skill gaps, and improve their chances of getting shortlisted. The application analyzes uploaded resumes, extracts relevant information, evaluates skills and experience, and provides actionable recommendations to make resumes more aligned with specific job requirements.

## 🚀 Features

- **Resume Upload:** Upload resumes in PDF format for automated analysis.
- **Resume Parsing:** Extract key information such as skills, education, experience, and projects.
- **AI-Powered Analysis:** Analyze resume content using AI to understand the candidate's profile.
- **Job Description Matching:** Compare resumes against job descriptions to identify relevant skills and missing keywords.
- **Skill Gap Analysis:** Highlight missing or weak skills required for a particular role.
- **Improvement Suggestions:** Provide recommendations to improve resume quality and relevance.
- **User-Friendly Interface:** Simple and interactive interface for seamless resume analysis.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Frontend:** Streamlit
- **AI/ML:** Natural Language Processing (NLP), AI-based text analysis, TextToSpeech, SpeechToText, SpeechRecognization, TextBlob
- **File Processing:** PDF text extraction

## ⚙️ How It Works

1. Upload your resume in PDF format.
2. The application extracts and processes the resume content.
3. Provide a job description for the desired position.
4. The AI analyzes the resume against the job requirements.
5. Review the analysis, skill gaps, matching results, and improvement suggestions.

## 🎯 Project Objective

The main objective of this project is to simplify the resume evaluation process by leveraging AI and NLP techniques. It helps candidates understand how well their resumes align with job requirements and provides meaningful insights to improve their professional profiles.
